内容更新说明 / How to update

本页由四个静态页面 + 一个内容数据文件组成。法规信息完成后，只需修改 assets/data.js 一个文件，四款产品的信息即可全部更新，二维码无需任何改动。

操作步骤

  1. 打开 assets/data.js，找到对应产品（P1 / P2 / P3 / P4）。
  2. 把其中的 待补充 / TBC、待上传 / To be uploaded 替换为真实内容。
  3. 文件下载：在 documents 数组中按格式添加 { title: "文件名", url: "文件地址" }。
  4. 保存后，用新的 data.js 覆盖服务器上同名文件即可，立即生效。

提示：所有内容集中在一个文件里，是为了让你以后更新信息时不必碰页面结构和二维码。
